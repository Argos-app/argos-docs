# Argos - Documentação

Repositório centralizado para toda a documentação do sistema **Argos**.

## Estrutura do Repositório

```
argos-docs/
├─ diagramas/      # Diagramas técnicos e arquiteturais (Vazio por enquanto)
|
├─ institucional/  # Documentação institucional e requisitos
│  └─ levantamento_de_requisitos.xlsx
|
├─ LICENSE
└─ README.md

```

## Como Contribuir

1. Organize novos documentos na pasta apropriada (`/diagramas` ou `/institucional`)
2. Mantenha nomes descritivos e em português
3. Atualize este README com novos arquivos significativos
